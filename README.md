# 🚀 C FILE VALIDATOR

> Strictly validate, compile, and inspect C source files directly from your terminal.

![npm version](https://img.shields.io/npm/v/c-file-validator-vimal?color=cb72f5)
![npm downloads](https://img.shields.io/npm/dm/c-file-validator-vimal)

## Features

- ⚙️ **Strict Checks:** Enforces `-Wall -Wextra -std=c11` compilation standards.
- 🧹 **Zero Junk Files:** Automatically cleans up temporary build binaries after inspection.
- ⚡ **Instant Execution:** Run anywhere via `npx`.

## Usage

Run directly via `npx`:

```bash
npx c-file-validator-vimal main.c
```

Or install globally:

```bash
npm install -g c-file-validator-vimal
```

```bash
c-check main.c
```
